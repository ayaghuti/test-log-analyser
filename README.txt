# Test Log Analyzer (Python)

This is a simple Python project designed to simulate a basic test automation and validation workflow.

## 🔧 Features
- Parses test log files
- Detects errors and warnings
- Extracts measured values
- Validates values against a threshold
- Generates PASS/FAIL test result
- Creates a simple test report

## 📁 Example Use Case
This tool mimics a simplified version of log analysis in system testing environments, where logs are analyzed to validate system behavior and detect failures.

## ▶️ How to Run

```bash
python main.py
